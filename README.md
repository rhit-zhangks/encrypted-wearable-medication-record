# Encrypted Wearable Medication Record
This is a senior capstone project!

## running the frontend
- make sure you have node and npm installed, this project requires a node version of at least 22 I think? i got the recent v26 LTS [from here](https://nodejs.org/en/download/archive/v26.13.0)
- `cd frontend` then `npm i` to install packages
- run `npm start` to host the site locally at [http://localhost:4200](http://localhost:4200/login)
